# PsychoTech Prep · הכנה למבחנים פסיכוטכניים

אפליקציית ווב אינטראקטיבית להכנה למבחני מיון פסיכוטכניים (סוללה קוגניטיבית ממוחשבת, עברית, שאלון אישיות וראיון עם מאבחנת).

## מה יש באתר

| | |
|---|---|
| **סימולציות** | 5 סימולציות (מלאה ~60 דק', מקוצרת, עברית, מילולית, כמותית-צורנית). כל פרק עם טיימר נפרד, ניווט חופשי וסימון לחזרה, בלי משוב עד הסוף – כמו במכון המיון. |
| **תרגול לפי נושאים** | 8 פרקים: הבנת הוראות, אנלוגיות, סדרות מספרים, בעיות חשבון, צורות ומטריצות, קשב ודיוק, היגיון ושלילות, עברית. סינון לפי תתי-נושאים, משוב והסבר מיידי. |
| **תרגול ממוקד** | בוחר שאלות באופן אדפטיבי לפי מדד חולשה לכל תת-נושא. |
| **ניתוח נתונים** | ציונים לאורך זמן, דיוק וקצב לכל פרק, טבלת חולשות, דרגה משוערת 1–9. |
| **אוצר מילים** | 309 מילים, הפכים, ביטויים, מילות קישור וכללי לשון. דף לימוד עם חיפוש והדפסה ל-PDF, כרטיסיות עם חזרה מרווחת (Leitner, 5 תאים), ובוחן. כל מילה שמופיעה בשאלות העברית נמצאת בדף, ותשובה שגויה בתרגול מחזירה את המילה לכרטיסיות. |
| **מחברת טעויות** | כל טעות נשמרת. אחרי 2 תשובות נכונות ברצף בחזרה היא יוצאת מהמחברת. |
| **ראיון עם מאבחנת** | 35 שאלות ב-9 קטגוריות, עם "מה בודקים" וטיפ לכל שאלה. תרגול עם טיימר, צ'קליסט STAR, בנק סיפורים, וטיפים לדינמיקה קבוצתית. |
| **שאלון אישיות** | תרגול עם ניתוח עקביות (פריטים הפוכים), סולם רצייה חברתית ושיעור תשובות קיצוניות. |

## ארכיטקטורה

```
src/
├── models/        # טיפוסי דומיין (Question, Attempt, QuizPlan)
├── generators/    # מחוללי שאלות פרוצדורליים (סדרות, חשבון, צורות, קשב, הוראות)
├── data/          # מאגרים מקוריים (אנלוגיות, עברית, היגיון, אישיות, ראיון) + הגדרות פרקים וסימולציות
├── services/      # questionEngine (בניית מבחנים), analytics (ניתוח חולשות), storage (שכבת שמירה), session
├── components/    # QuestionView, FigureView (SVG), Charts
├── pages/         # המסכים
└── utils/         # PRNG עם seed, ובניית שאלות
```

החלטות עיקריות:
- **שאלות מחוללות ולא מועתקות.** פרקים כמותיים וצורניים נוצרים בקוד, כך שיש מספר בלתי מוגבל של שאלות ותשובה נכונה שמובטחת בחישוב. במטריצות כל מסיח שובר בדיוק חוק אחד, כמו במבחנים האמיתיים.
- **מדד חולשה:** שיעור טעויות מוחלק בהחלקת Laplace עם דעיכה אקספוננציאלית (זמן מחצית של 30 תשובות), ועוד קנס על קצב איטי. כך שאלה בודדת לא "מסמנת" נושא, ושיפור אמיתי נראה בגרף.
- **אוצר מילים מחובר לתרגול:** כל פריט במילון מקושר לשאלה בבנק (`questionId`). בסוף כל מבחן, תשובה שגויה על שאלה כזו מעבירה את הפריט לתא 0 ומסמנת אותו, כך שסבב הכרטיסיות הבא מתחיל בדיוק מהמילים שעלו נקודות. המסיחים בשאלות שנוצרות מהמילון נבחרים לפי אותו חלק דיבר ובלי מילים נרדפות (תגי אשכול), כדי שלא תהיה יותר מתשובה נכונה אחת.
- **סטטי לגמרי:** בלי שרת. הנתונים נשמרים ב-localStorage, ויש ייצוא וייבוא לגיבוי. HashRouter ו-`base: './'` מאפשרים לפרוס על כל אחסון סטטי.
- TypeScript במצב strict, פיצול קוד ברמת route, ובלי ספריות גרפים (גרפי SVG קלים).

## הרצה מקומית

```bash
npm install
npm run dev        # פיתוח
npm run build      # בנייה ל-dist/
npm run validate   # בדיקת תקינות לכל המחוללים והמאגרים (15K שאלות)
```

## הערה

כל השאלות מקוריות ונכתבו או נוצרו לצורכי תרגול. אין בפרויקט שאלות ממבחנים אמיתיים. מבנה הפרקים מבוסס על מידע פומבי על מבחני מיון ממוחשבים בישראל, והמבנה המדויק משתנה בין מכונים ותפקידים.
